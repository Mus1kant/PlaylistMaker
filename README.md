Playlist Maker
==============

Playlist Maker — учебное Android-приложение для поиска музыкальных треков. Проект разработан на Kotlin с использованием Jetpack Compose в рамках обучения Android-разработке. На текущем этапе реализованы задания спринтов 3–6.

Возможности приложения
----------------------

- Главный экран с переходами к поиску и настройкам.
- Поиск треков по названию композиции или имени исполнителя без учёта регистра.
- Отображение результатов в прокручиваемом списке `LazyColumn`.
- Индикатор загрузки, сообщения о пустом результате и об ошибке.
- Очистка поисковой строки с отменой текущего поиска.
- Сохранение поискового запроса и результатов при повороте экрана.
- Переход на экран с информацией о выбранном треке.
- Экран настроек с действиями «Поделиться приложением», «Написать разработчикам» и «Пользовательское соглашение».

Технологии и архитектура
------------------------

- **Kotlin** — основной язык разработки.
- **Jetpack Compose** — интерфейс приложения.
- **MVVM, ViewModel, StateFlow** — хранение состояния экрана поиска.
- **Kotlin Coroutines** — выполнение поиска и обработка асинхронных операций.
- **Koin** — внедрение зависимостей.
- **Navigation Compose** — переходы между экранами.
- **Clean Architecture** — разделение на слои `data`, `domain` и `ui`.

Назначение основных слоёв
-------------------------

**Data** — источник учебных данных `Storage`, DTO, преобразование моделей и реализация репозитория поиска.

**Domain** — модель `Track`, интерфейсы репозитория и интерактора, который вызывается из SearchViewModel.

**UI** — экраны на Jetpack Compose, навигация, ViewModel и состояния интерфейса.

Как работает поиск
------------------

Сейчас приложение использует локальный учебный набор из восьми композиций The Beatles. ViewModel получает интерактор через Koin и не обращается непосредственно к Data. Класс `Storage` хранит исходные данные, а `TracksRepositoryImpl` отбирает треки по введённому запросу. Поиск выполняется без учёта регистра; продолжительность преобразуется в формат `mm:ss`.

Во время поиска показывается индикатор загрузки. Если совпадений нет, отображается экран «Ничего не найдено». Для состояния ошибки предусмотрена отдельная заглушка «Нет интернета»; поскольку источник данных локальный, она проверяется через Compose Preview, а не отключением сети.

Сборка и запуск
---------------

1. Склонировать репозиторий или скачать исходный код.
2. Открыть папку проекта в **Android Studio**.
3. Дождаться завершения **Gradle Sync**.
4. Запустить Android-эмулятор или подключить устройство.
5. Выбрать конфигурацию **app** и нажать **Run**.

Для сборки APK из терминала в Windows можно выполнить:

```powershell
.\gradlew.bat :app:assembleDebug
```

Для работы учебного поиска подключение к интернету не требуется.
